# Insurance Policy and Claims Management System

A beginner-friendly MERN project for managing insurance customers, products, policies, claims, premium payments, and reports.

## Project plan

1. Set up the frontend and backend folders.
2. Add MongoDB models, authentication, and API routes.
3. Build the React screens and connect them to the API.
4. Test the main workflows and document how to run the project.

## Tech stack

- React and Vite
- Node.js and Express
- MongoDB and Mongoose
- Plain CSS

## Folder structure

```text
backend/
  config/       MongoDB connection
  controllers/  API request handlers
  middleware/   Login and role checks
  models/       MongoDB collections
  routes/       API URLs
  seed/         Demonstration data
  uploads/      Claim documents
frontend/
  src/
    components/
    context/
    pages/
    services/
```

More installation instructions and demonstration accounts will be added after implementation.
